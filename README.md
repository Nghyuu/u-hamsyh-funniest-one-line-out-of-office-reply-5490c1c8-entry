## Entry

`main.ts` writes a single funny one-line out-of-office reply (1–160 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
